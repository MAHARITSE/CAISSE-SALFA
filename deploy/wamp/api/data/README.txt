CAISSE SALFA — dossier de travail
=================================

Ce dossier est interdit d'accès depuis le navigateur (.htaccess).

Aucune installation n'est nécessaire : la configuration se crée toute seule au
premier appel de l'application.

Contenu après le premier démarrage :
  salfa-config.php   accès MySQL, écrit automatiquement (si le dossier parent
                     n'est pas inscriptible, le fichier s'écrit à côté de
                     C:\wamp64\www\caisse-salfa, hors www)
  sauvegardes/       dumps SQL téléchargés depuis l'onglet « Données & sauvegardes »
  journaux/          traces de dépannage
